### telegram-bridge *(coming soon)*
> Two-way Telegram ↔ Claude Code bridge — control your AI workflow from your phone

Claude Code's CLI is terminal-bound. This bridge makes it mobile: send prefixed commands from Telegram → routed to the right Claude session → responses back in chat. Runs persistently via pm2 + launchd, survives reboots, registered as an MCP server.
